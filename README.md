# Kicherkiste 💖💜

Spiele für zwei – mit Baby-Design (Einhorn Kiki) und Lila-Design (Katze Kuro):

- **Escape-Abenteuer** – zusammen statt gegeneinander: 7 Geschichten (z. B. „Flucht aus dem Regenbogenschloss“), je 4 Räume. Einer ist an den **Händen**, der andere hat das **Wissen** – nur wer redet, kommt raus. Braucht zwei Handys.
- **Galgenmännchen**, **Wer bin ich?**, **Zahl erraten** (1–100)
- **Kritzelspiel** (einer zeichnet, einer rät) und **Pantomime** (einer stellt dar, einer rät)
- **Herzchen versenken** – Einhörner, Wolken und Katzen verstecken und finden, mit Einhorn-Bombe

**Spielen:** https://pxrple01.github.io/Haushalt/

## Auf den Home-Bildschirm legen
- **iPhone (Safari):** Seite öffnen → Teilen-Knopf → „Zum Home-Bildschirm“.
- **Android (Chrome):** Seite öffnen → Menü ⋮ → „App installieren“ bzw. „Zum Startbildschirm hinzufügen“.

Danach startet die Kicherkiste wie eine App – im Modus „Nebeneinander“ sogar ohne Internet.

## So funktioniert’s
1. **Wer spielt?** – auf deine Hälfte vom Herz tippen. Das Design passt sich an (änderbar im Zahnrad-Menü).
2. **Modus wählen:**
   - **Nebeneinander:** ein Handy reicht. Geheimes wird mit Sichtschutz eingegeben („Gib das Handy an …“), Fragen sagt ihr euch laut.
   - **Weit weg:** jeder spielt am eigenen Handy, live verbunden. Beim ersten Mal auf **beiden** Handys denselben Code eingeben (z. B. ein Wort, das nur ihr kennt).
3. Spiel antippen, loslegen. Die **Duell-Bilanz** zählt mit, wer wie oft gewonnen hat.

## Escape-Abenteuer in Kürze
- Auf beiden Handys denselben Code eingeben (Weit weg), dann eine Geschichte antippen und **Abenteuer starten**. Das andere Handy bekommt eine Einladung.
- Stufen: **Gemütlich** (ohne Zeit), **Normal** (25 Minuten), **Knifflig** (15 Minuten, schwerere Rätsel). Fehler kosten 20 Sekunden, ein Tipp 1 Minute.
- Die Rätsel werden jedes Mal neu gemischt – jede Geschichte kann man immer wieder spielen. Am Ende gibt es bis zu 3 Sterne und einen Rekord pro Geschichte.

## Gut zu wissen
- Für „Weit weg“ nutzt die Kicherkiste dieselbe Cloud wie eure Watchlist – aber **nur für Live-Nachrichten**, es wird dort nichts gespeichert.
- Spitznamen lassen sich im Zahnrad-Menü ändern. Auf „Wer spielt?“ stehen immer die echten Namen.
- Töne, Vibration und „Bewegung reduzieren“ sind im Zahnrad-Menü einstellbar.
